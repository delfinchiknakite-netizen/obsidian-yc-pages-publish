# YC Pages Publish

Obsidian-плагин: публикует заметки и целые папки как **временные сайты** (с TTL) на
**Яндекс Облаке** (Object Storage + Cloud Function + API Gateway). Правый клик по файлу или
папке (на телефоне — иконка на панели / меню редактора) → «Опубликовать как сайт».

- **Заметка → страница**: markdown рендерится в HTML, отдаётся по короткой ссылке.
- **Папка → многостраничный сайт**: повторяет дерево папок Obsidian — у каждой папки свой
  индекс (хлебные крошки + подпапки 📁 + список заметок с поиском, фильтрами и сортировкой,
  которые авто-строятся из frontmatter).
- **Картинки** из заметок заливаются в бакет (presigned upload), ссылки переписываются.
- **TTL** 7/30/90 дней: истёкшее скрывается на сайте (JS) и физически удаляется Object Storage
  lifecycle. Крон не нужен.
- **Журнал** публикаций в заметке `Ссылка на сайты.md` (дата, TTL, **QR-код**); истёкшие строки
  удаляются автоматически.
- **QR-код** ссылки в окне результата (показать/отсканировать с телефона).
- Работает на десктопе и на телефоне.

> ⚠️ Плагину нужен **свой бэкенд** на Яндекс Облаке (разворачивается один раз, см. ниже).
> Стоимость — в пределах бесплатного лимита Cloud Functions (~0 ₽).

## 1. Развернуть бэкенд (один раз)

Всё в папке [`backend/`](backend/) — Terraform поднимает бакет (public + static hosting +
lifecycle), сервисный аккаунт, Cloud Function (рендер MD→HTML) и API Gateway.

```bash
cd backend/terraform
cp terraform.tfvars.example terraform.tfvars   # впишите bucket_name и create_token
export TF_CLI_CONFIG_FILE="$PWD/.terraformrc"  # YC-зеркало провайдеров (для РФ)
export YC_TOKEN=$(yc iam create-token)
terraform init
terraform apply
```

После `apply` в outputs будут:
- `api_url` — эндпоинт (нужен плагину),
- `site_url` — адрес будущего сайта,
- (токен — тот, что вы задали в `terraform.tfvars`).

Подробности и вариант через `yc` CLI — в [`backend/README.md`](backend/README.md).

## 2. Установить плагин

### Через BRAT (рекомендуется — авто-обновления, работает на телефоне)
1. Установите **Obsidian42 - BRAT** (Community plugins).
2. BRAT → *Add Beta plugin* → `delfinchiknakite-netizen/obsidian-yc-pages-publish`.
3. Включите **YC Pages Publish**.

### Вручную
Скопируйте `main.js` и `manifest.json` в `<vault>/.obsidian/plugins/yc-pages-publish/`,
включите плагин.

## 3. Настроить плагин

Settings → **YC Pages Publish**:
- **API URL** — `api_url` из шага 1.
- **Токен** — `create_token` из шага 1.
- (опц.) TTL по умолчанию, параллельных загрузок, путь заметки-журнала.

При **первой публикации** плагин сам создаёт корневые файлы сайта (`index.html`, `new.html`,
`error.html`, `manifest.json`) в бакете (действие `bootstrap`). Можно вызвать вручную кнопкой
**«Инициализировать»** в настройках.

## 4. Пользоваться

- **Заметка**: ПКМ по `.md` → «Опубликовать как сайт» (или иконка 🌐 / меню редактора / палитра).
- **Папка**: ПКМ по папке → «Создать сайт из папки».
- В окне результата — ссылка, кнопка **«Скопировать ссылку»** и **QR-код**.
- Все ссылки копятся в `Ссылка на сайты.md`; истёкшие уходят сами.

## Синхронизация на несколько устройств

- **BRAT** ставит плагин на любом устройстве и обновляет сам.
- Либо через **Obsidian Git** — папка плагина синхронизируется как часть vault.
- `data.json` (API URL + токен) не переносится автоматически из соображений безопасности —
  задайте их в настройках на каждом устройстве.

## Сборка из исходников

Исходник — [`src/main.js`](src/main.js) (чистый), QR-библиотека — `src/qrcode.js`.
Корневой `main.js` собирается скриптом (вшивает qrcode):

```bash
node src/build.js main.js
```

Архитектура плагина — [`src/ARCHITECTURE.md`](src/ARCHITECTURE.md).
